3 abordagens — qual é a tua?

Mesma stack base, scopes diferentes. Recomendação no topo.

C

Hybrid Studio + Generate (recomendado)

Duas superfícies ligadas:

  • Generate — hub estilo Lychee (barra central + galeria "My assets"). Prompts: copy, imagem, batch de variações ("3 posts Sardinia Maio").
  • Studio — canvas real (Konva/Fabric) com brand-kit guardrails: paleta, fontes, logos sempre à mão. Cliente arrasta, edita, exporta.
  • Output do Generate cai direto no Studio para refinar.
  • 4 formatos: email HTML, social 1:1/4:5, carrossel, story 9:16.

Pros: Honra "Express + AI". Wow-factor da Lychee + controlo do Express.
Cons: Build maior. ~8–10 semanas até MVP útil.

A

Phased: Studio primeiro, AI em v2

v1 = canvas + template gallery + asset library + export. Zero AI no MVP.
v2 = AI copy + AI imagem. v3 = agent orchestrator.

Pros: Ship rápido (~4–5 semanas para v1), valida com Eleggia antes de AI.
Cons: Falta a vibe AI que pediste — sem wow.

B

AI-first: agente é o produto, canvas é minimal

v1 = barra central Lychee-style faz batches inteiros; "edit" é só swap de texto/imagem.
Canvas real só em v2.

Pros: Demo wow imediata, diferenciação grande.
Cons: Inverte o que escolheste ("Open canvas"); se AI falhar, o cliente fica sem escape; difícil ajustar pixels finos.
